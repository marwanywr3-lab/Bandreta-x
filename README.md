# الموقع الرسمي لبندريتا (BanderitaX)

موقع تعريفي سريع وخفيف مبني بـ HTML / CSS / JavaScript جاهز للرفع المباشر على **GitHub Pages** أو **Cloudflare Pages**.

## هيكل الملفات
- `index.html`: الصفحة الرئيسية للموقع.
- `style.css`: ملف التصميم والألوان وتأثير التمويه الجانبي (Blur) للبنر.
- `config.js`: **ملف التحكم الكامل** (من هنا تغيّر جملة الترحيب، تضيف صور جديدة للبنر مع روابطها، أو تعدل الروابط والمنصات).
- `app.js`: محرك تشغيل البنر القابل للتقليب والبطاقات التفاعلية.
- `assets/logo.jpg`: صورة شعار القناة الأساسية.

## طريقة التعديل السريع مستقبلاً
افتح ملف `config.js`:
1. **تغيير جملة الترحيب:** عدّل قيمة `welcomeText`.
2. **إضافة صور جديدة للبنر (سواء صور فقط أو صور تفتح رابط عند الضغط):**
   أضف عنصراً جديداً داخل قائمة `banners` بهذا الشكل:
   ```js
   {
     image: "assets/new-banner.jpg",
     alt: "وصف الصورة",
     link: "https://banderitax.store/", // اتركه "" إذا كانت صورة بدون رابط
     fitMode: "square-blur" // أو "cover" لملء البنر بالكامل
   }
   ```
   *(بمجرد وجود أكثر من صورة، ستظهر أسهم ونقاط التقليب ويعمل السحب باللمس والتقليب التلقائي فوراً).*

## طريقة الرفع على GitHub Pages
1. أنشئ مستودعاً (Repository) جديداً على GitHub.
2. ارفع جميع الملفات الموجودة داخل هذا المجلد مباشرة إلى المستودع (تأكد أن `index.html` في المسار الرئيسي).
3. ادخل إلى **Settings** > **Pages**، واختر فرع `main` ثم اضغط **Save**.
