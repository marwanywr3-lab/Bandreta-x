# الموقع الرسمي لبندريتا (BanderitaX)

موقع تعريفي سريع وخفيف جاهز للرفع المباشر على **GitHub Pages**.

## هيكل الملفات
- `index.html`: الصفحة الرئيسية للموقع.
- `style.css`: ملف التصميم والألوان وتنسيق البنر الطولي.
- `config.js`: **ملف التحكم الكامل** (لتعديل الاسم، النبذة، الإيميل، جملة الترحيب، شرائح البنر، سرعة التقليب، والروابط).
- `app.js`: محرك تشغيل البنر القابل للتقليب والبطاقات التفاعلية.
- `logo.jpg` / `potato.jpg` / `store.jpg`: صور الشعارات المستخدمة في البنر والروابط.

## طريقة تعديل سرعة التقليب أو الشرائح
افتح ملف `config.js`:
- لتغيير سرعة التقليب التلقائي، عدّل قيمة `intervalMs` (مضبوطة حالياً على `3800` أي 3.8 ثانية).
- لتعديل صور البنر أو روابطها أو الشارة التوضيحية `badgeText`، عدّل قائمة `banners`.
