# الموقع الرسمي لبندريتا (BanderitaX)

موقع تعريفي سريع وخفيف جاهز للرفع المباشر على **GitHub Pages**.

## هيكل الملفات
- `index.html`: الصفحة الرئيسية للموقع.
- `style.css`: ملف التصميم والألوان وتنسيق البنر الطولي.
- `config.js`: **ملف التحكم الكامل** (لتعديل الاسم، النبذة، الإيميل، جملة الترحيب، صور البنر، والروابط).
- `app.js`: محرك تشغيل البنر القابل للتقليب والبطاقات التفاعلية.
- `logo.jpg`: صورة شعار القناة الأساسية (موجودة في المسار الرئيسي وكذلك داخل مجلد `assets` لضمان ظهورها دائماً).

## طريقة الرفع على GitHub Pages بدون مشاكل في الصور
1. فك الضغط عن الملف المضغوط.
2. ارفع **جميع الملفات** (`index.html`, `style.css`, `config.js`, `app.js`, `logo.jpg`, ومجلد `assets`) مباشرة إلى المسار الرئيسي للمستودع (Repository) على GitHub.
3. تأكد أن ملف `logo.jpg` مرفوع بجانب `index.html`.
